# 🎨 Темы оболочки CtOs (XMB)

Папка — дом тем оболочки. Два слоя:

```
CtMusic/themes/
├── builtin/            ← встроенные темы (зафиксированные заимствования из PSP)
│   ├── xmb_classic/    ← официальная прошивка Sony (6.35/6.60)
│   ├── ark4_dark/      ← кастом ARK-4 / cIPL
│   ├── gen_d3_orange/  ← кастом 5.50 GEN-D3
│   └── mac_leopard/    ← кастомная «Mac OS X Leopard»
└── custom/             ← КАСТОМНЫЕ ТЕМЫ ПОЛЬЗОВАТЕЛЕЙ (для нашей ОС)
```

## Правило «скинул — привязалось»
1. Пользователь кладёт папку темы в `themes/custom/<имя_темы>/`.
2. Оболочка при старте (или Settings → Theme Settings → «Обновить темы»)
   сканирует `custom/` и добавляет каждую валидную тему в список.
3. Переключение: **Settings → Theme Settings → <тема>** — как на PSP.
4. Битые темы (нет `theme.json` или не хватает файлов) не падают системой:
   они помечаются как `invalid` в логе Early Boot и пропускаются.

## Формат темы
```
<имя_темы>/
├── theme.json          ← манифест (обязателен)
├── wallpaper.png       ← фон XMB (480×272, или больше — оболочка ужмёт)
├── wave.png            ← «волна» фона (полоса-градиент, можно прозрачный PNG)
├── icons/              ← иконки категорий и пунктов (PNG 48×48 и 24×24)
│   ├── settings.png
│   ├── extras.png
│   ├── photo.png
│   ├── music.png
│   ├── video.png
│   ├── game.png
│   └── network.png
├── boot.webm           ← (опционально) свой загрузочный ролик, см. Readme
└── sounds/             ← (опционально) звуки навигации: select.wav, back.wav
```

## Манифест `theme.json`
```json
{
  "name": "My Night Theme",
  "author": "RJ",
  "version": "1.0",
  "base": "ark4_dark",
  "colors": {
    "highlight":      "#FF9A1F",
    "text":           "#FFFFFF",
    "text_dim":       "#B8B8C8",
    "wave_top":       "#1A1A2E",
    "wave_bottom":    "#16213E",
    "info_panel":     "#202040"
  },
  "fonts": { "main": "system", "size": "normal" },
  "visualizer": { "style": "wave", "color": "#00FF66" }
}
```

Поля:
*   `name` / `author` / `version` — показываются в Theme Settings;
*   `base` — тема-родитель: недостающие файлы наследуются у неё
    (кастомная тема может состоять из одного `theme.json` с цветами);
*   `colors` — палитра оболочки (подсветка, текст, волна, инфо-панель);
*   `visualizer` — стиль и цвет визуализатора плеера (референс: зелёная
    осциллограмма PSP-Go).

## Эволюция интерфейсов PS3 → PS4 → PS5 (референсы RJ, 2026-10)
Пользователь собрал скринкаст референсов интерфейсов трёх поколений.
Что честно берём для CtOs и на каком железе это позволено
(приоритеты «ОС не парит железо»: слабый = PSP-1004 база):

| Элемент | PS3 (XMB) | PS4 | PS5 | CtOs решение |
|---|---|---|---|---|
| Навигация | горизонтальная волна-лента, категории | ряд иконок крупно | ряд иконок сверху, инфо-карточка справа | база: XMB-волна (слабое железо); расширенный ряд иконок + карточка — флаг на средних стендах |
| Фон под выделением | статичная тема или лёгкий градиент | динамический арт-фон | арт-фон +tooltip | наш `wallpaper.png` (один на тему); «фон меняется под выделенным пунктом» = опция темы, честно отключаемая на слабых |
| Инфо-карточка приложения | подпись под иконкой | полоса-заголовок | карточка справа (цена/прогресс/трофеи) | карточка = инфо-панель `info_panel` из theme.json: имя, версия, размер, честное состояние (готово/нужна установка) |
| Onscreen-клавиатура | системная PSP | тёмная сетка | сетка + трекпад-полоса | ТЕРМИНАЛ уже задаёт клавиатуру; визуальный стиль берёт тему (тёмная сетка PS4 — дефолт `ark4_dark`) |
| Оверлей «поделиться/сообщение» | — | карточка-шторка слева | карточка + поле сообщения | оверлей = модальное окно ОС: те же честные правила, стиль/цвет берёт тема |
| Строка статуса | верхние метки XMB | верх: иконки, время, профиль | то же + «…» меню настроек | наша полоса статуса XMB: часы, батарея/носитель, текущая тема |
| Progress/трофеи | — | полоса прогресса | карточка Progress 0/N | честный аналог: честная строка прогресса установки/синхронизации в карточке |

Правила внедрения (честные):
1. **Базой остаётся XMB** — именно он честно отвечает слабому железу и уже зафиксирован
   четырьмя встроенными темами.
2. «PS5-стиль» — это не новая оболочка, а **скин поверх XMB**: другой ряд иконок,
   карточка справа, тёмная палитра. Оформляем как очередную тему `builtin/ps5_style`
   (или кастом) с обязательным честным деградирующим режимом: без динамических
   фонов, без прозрачностей по дефолту.
3. PS3/PS4/PS5-материалы заимствуем как **идеи**, файлы Sony в репозиторий
   не кладём (правило лицензионной чистоты, см. PSP_REF.md).

### Дополнение по второй партии референсов (2026-10, партия 2)
*   **PSP-плеер (Group Mode, A-B, P-MODE, CLEAR)** — честный референс расширенного
    управления музыкой для CtMusic: A-B-повтор и режимы воспроизведения в ту же
    нижнюю линейку плеера, что и визуализатор.
*   **PS3 Settings-дерево «Restore Default / Theme Settings / Power Save»** —
    подтверждение нашей структуры Settings: восстановление по умолчанию —
    отдельный пункт, энергосбережение живёт рядом с темой (синхронизируем с
    SCHED_SPEC: No-HZ/пустые тики управляются отсюда).
*   **XMB, воссозданный на Android (сторонний лаунчер)** — подтверждение, что
    XMB-скин переносим на разное железо; наш tzель «слабое железо» — тот же путь.
*   **Nintendo Switch UI (волна + ряд иконок + панель настроек)** — тот же жанр,
    логотипы их как вымышленный «своих пути» не упоминаем; для нас аргумент, что
    волна не устарела; стиль плоских иконок бережём в `builtin/ps5_style`.
*   **Инфографика «PlayStation User Interfaces» (PS1 → PS2 → PS3 → PS4 → PS5,
    Vita, Portal)** — ленточка эволюции: Memory Card → космос → волна →
    плитки-бабблы → карточки. Для CtOs фиксируем этап 3 (волна) как базу и этап 5
    (карточки) как скин-опцию на средних стендах.
