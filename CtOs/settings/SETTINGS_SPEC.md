# ⚙️ SETTINGS_SPEC — Обычные и Секретные настройки CtOs

Место: `CtOs/settings/`. Статус: спецификация (реализация — прикладной
слой Settings XMB; стадии-0 честно дают только ячейки-флаги).
Структура честная: стандартные параметры — в подменю Обычные; инженерные,
скрытые сервисные и отладочные — в блок Секретные (доступ только через
`rootcmd:` — TERMINAL_SPEC).

Привязка ревизий пользователя: PSP → **P1000Fat/P2000/P3000/P1000Str**
(Vita=внутренний «гость-профиль»), домашние → **PS1/PS2/PS3/PS4/PS5**.
Наше честное железо-хост: **ACER Revo R3700 (13 Вт потолок)** — пункты,
недостижимые на нём аппаратно, честно помечены `[limited R3700]`.

## Блок Обычные (подменю Settings)

### Управление системой и памятью
- Информация о системе / Сведения (все ревизии)
- Имя консоли / Псевдоним (PS3-PS5, PSP-ветка)
- Язык системы, Набор символов
- Обновление системного ПО (+ авто-обновление PS3/PS4/PS5)
- Управление памятью / Хранилище (все ревизии)
- Форматирование накопителя / Memory Stick
- Резервное копирование и восстановление (PS3-PS5, PSP-ветка)
- Восстановление настроек по умолчанию / Сброс консоли
- Перенос данных с другой консоли (PS4/PS5)
- Управление данными сохранённых игр в облаке (PS3-PS5)
- Утилита данных игры / Удаление данных установки (PS3)
- Автозапуск UMD-диска (PSP-ветка)
- Кэширование данных с UMD (P2000/P3000)
- Разрешить WMA / Flash Player (PSP-ветка)
- Автоподключение USB, Зарядка от USB (P2000/P3000)
- Сведения о батарее (PSP-ветка) `[limited R3700: источник = БП]`
- Скорость чтения CD/DVD Fast/Standard (PS2)
- Сглаживание текстур PS1 (PS2/PS3)

### Экран и видеовывод
- Формат 4:3/16:9, Видеосигнал RGB/YCbCr (PS2/PS3)
- Разрешение: 480p…1080p честно на R3700; 1440p/4K/8K — `[limited R3700]`
- Частота 120 Гц, VRR, ALLM (PS5) `[limited R3700]`
- Deep Color, Диапазон RGB, HDR-калибровка (PS3-PS5)
- Цветовое пространство PSP Normal/Wide, авторегулировка подсветки (P3000)
- Вывод на внешний ТВ/кабель, Flicker Reduction (P3000)
- Суперсэмплинг / Boost Mode (PS4 Pro)

### Звук и аудиовывод
- Выход (Оптика/HDMI/AV/Динамики), цифровой выход (PS2)
- Приоритет формата PCM/Dolby/DTS (PS3-PS5)
- 3D-звук ТВ/наушники, Dolby Atmos (PS5) `[limited R3700]`
- AVLS, Динамический нормализатор (PSP/PS3)
- Звуки интерфейса, Beep при старте (PS5)
- Микрофон по умолчанию выкл (PS5)

### Сеть и дистанционное воспроизведение
- Настройка LAN/Wi-Fi (PS3-PS5, PSP-ветка)
- Проверка соединения (скорость + NAT)
- Ad-Hoc канал (PSP-ветка), DLNA-сервер (PS3)
- Remote Play (PS3-PS5, PSP-ветка)
- Wi-Fi Direct Vita (PS4), RSS-каналы (PSP-ветка)

### Устройства и аксессуары
- Bluetooth-контроллеры; вибрация/триггеры/свет-панель (PS4/PS5)
- Способ связи контроллера, калибровка DualSense Edge (PS5)
- Гарнитура/микрофон BT (PS3-PS5), камера (PS3-PS5), VR/отслеживание `[limited R3700]`
- Мышь и внешняя клавиатура (PS3-PS5)

### Учётная запись, безопасность, родительский контроль
- Автовход, пароль профиля (PS4/PS5)
- Подписки/PS Network, основная консоль (PS4/PS5)
- Родительский контроль, пароль браузера (все)
- 2FA (PS3-PS5), приватность профиля/друзей (PS4/PS5)

### Энергосбережение и питание (Powermanagment — честный приоритет)
- Таймер автоотключения (все ревизии)
- Автовыключение подсветки (PSP-ветка) → честный аналог: дисплей ПК
- Автоотключение контроллеров (PS4/PS5)
- Функции режима покоя: питание USB, фоновая загрузка (PS4/PS5)
- Таймер заставки (P2000/P3000)
- Энергосбережение Wi-Fi (PSP-ветка)
- ➕ **Governor CPU**: idle / игра / максимум (EMULATION_SPEC, 13 Вт)
- ➕ Термочувствительность честного предохранителя: предупреждение/спад частоты/паника
- ➕ Тик частоты ядра: честный No-HZ вкл/выкл (спринт Д даёт флаг)

### Дата, время и регион
- Дата/время вручную, NTP-синхронизация (PS3-PS5, PSP-ветка)
- Часовой пояс/летнее время, формат 12/24

### Оформление и интерфейс
- Выбор/установка тем (PS3, PSP-ветка) — честная база спринтов Темы/Builtin
- Цвет фона XMB, шрифт (PS3)
- Подтверждение X/O местами (PS4/PS5)
- Уведомления (блокировка во время игр/видео)

### Игровой процесс и доступность
- Предустановки игр: сложность/Производительность/Качество (PS5)
- Инверсия осей (PS5), транскрипция чата (PS4/PS5)
- Цветовая инверсия, зум, высокий контраст (PS4/PS5)
- Автозапись трофеев, спойлер-предупреждения (PS5)

### Воспроизведение дисков (BD/DVD)
- Язык меню/аудио/субтитров (все)
- Cinema Conversion (PS3), DVD Upscaler (PS3)
- Динамический диапазон аудио (PS3/PS4), BD-Live (PS3/PS4)

## Блок Секретные (только rootcmd:, в Settings их НЕТ)

- Безопасный режим / Safe Mode (меню восстановления)
- Rebuild Database (PS3-PS5), Restore File System (PS3-PS5)
- Обновление прошивки из Safe Mode с USB (PS3-PS5)
- Принудительная очистка кэша системного ПО (PS5)
- Сброс видеосигнала до базового разрешения (PS3-PS5)
- Смена типа HDCP / игнорирование HDCP (PS4/PS5)
- Debug Settings (только TestKit/DevKit; розничные — честно нет)
- Kernel Error Logs (PS3-PS5) → честно: журнал ядра VM
- Водяные знаки производительности DevKit — честно нет
- Принудительная эмуляция дисковода по сети (PS3/PS4)
- Fake Plus — эмуляция подписки без сети — **честно отвергнута**
  (правило: никаких подделок подписки; пункт честно удалён)
- Service/Factory Mode, программатор (PS3)
- Смена региона привода JIG-card (PS2/PS3)
- Скрытый лог вентилятора/датчиков (PS3/PS4) → честный термолог
- Скрытая комбинация PS3 (L1+L2+R1+R2+L3+Down)
- Сервисный тест кнопок/дисплея (PSP-ветка)
- Полное отключение экрана при сохранении звука (PSP-ветка)
- Принудительное выключение зависшей консоли (10–15 с питания)

Правила повторяются из TERMINAL_SPEC: список Секретных НЕ показывается
`rootcmd: help`; каждый вызов честно в журнале; нормальные параметры
правятся и из меню, и через `set <параметр> <значение>`.
