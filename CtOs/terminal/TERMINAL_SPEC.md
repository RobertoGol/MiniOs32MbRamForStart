# ⌨️ Terminal — системная консоль CtOs

Место в системе: **меню приложений, сразу под Settings** (следующее приложение).
Аналог `cmd` и `PowerShell 7.x`, но скрипты — на нашем языке KINII, «понятные
всем». Скрипты терминала лежат в `.vc`/`.ctos` и исполняются рантаймом CtOs.

## Принцип совместимости
Для удобства терминал принимает **команды cmd и PowerShell 7.6.7** (имена и
семантика) и транслирует их в системные вызовы CtOs. Своя команда всегда
пишется так же, как на PSP-стиле: коротко, глагол-существительное.

## Базовые команды (стартовый набор)

| Ввод (cmd / pwsh) | Команда CtOs | Что делает |
|---|---|---|
| `dir` / `ls` / `Get-ChildItem` | `dir [путь]` | список файлов; разбор по магическим байтам (см. Readme) |
| `cd` / `Set-Location` | `cd <путь>` | смена каталога |
| `type` / `cat` / `Get-Content` | `cat <файл>` | вывести файл (текстовый) |
| `mkdir` / `New-Item -ItemType Directory` | `mkdir <имя>` | создать каталог |
| `del` / `rm` / `Remove-Item` | `rm <цель>` | удалить файл/каталог |
| `copy` / `cp` / `Copy-Item` | `cp <откуда> <куда>` | копировать |
| `move` / `mv` / `Move-Item` | `mv <откуда> <куда>` | переместить/переименовать |
| `cls` / `clear` / `Clear-Host` | `cls` | очистить экран |
| `ipconfig` / `Get-NetIPConfiguration` | `net_all` | диагностика сети (опкод 0x20) |
| `ping` | `go <хост>` | эхо-запрос (опкод 0x25) |
| `tracert` / `Test-NetConnection -Trace` | `trace <хост>` | трассировка (опкод 0x26) |
| `ipconfig /flushdns` | `net_flush` | сброс DNS-кеша (опкод 0x23) |
| `tasklist` / `Get-Process` | `ps` | список задач планировщика ядра |
| `kill` / `Stop-Process` | `kill <id>` | завершить задачу |
| `systeminfo` | `sysinfo` | экран System Information (версия, ник, MAC) |
| `exit` | `terminate` | закрыть терминал |

Скрипты: файл `скрипт.vc` исполняется командой `run <файл>` — как `void.run`.

## rootcmd — секретные настройки

Часть параметров системы **скрыта из меню настроек** и правится только из
терминала владельцем:

```
rootcmd: <параметр> <значение>
```

Примеры:
```
rootcmd: ring0.guard off          // снять защиту Ring 0 (только для отладки)
rootcmd: boot.video off           // отключить загрузочный ролик .webm
rootcmd: mem.pool 32              // жёсткий лимит пула ОЗУ в МБ
rootcmd: theme.force builtin/ark4_dark
rootcmd: fs.scan.delay 1000       // честная задержка скана диска после монтажа
rootcmd: fs.scan.now              // честный повторный скан вручную
rootcmd: fs.osdisk ms0:           // честная пере-метка системного диска
```

Подсистемы rootcmd (полный реестр — в EMULATION_SPEC «rootcmd»):
диски/скан/правила записи, темы, память, guard. Скрытые из Settings —
не просто так: честный доступ только к владельцу.

Правила честности:
1. Скрытые параметры **не отображаются** в меню Settings и в `rootcmd: help`
   — их перечень знает владелец (хранится в `sql.core` под ключом root).
2. Обычные параметры — те, что не скрыли, — правятся и из меню (по подменю),
   и из терминала: `set <параметр> <значение>`.
3. Каждый вызов `rootcmd:` пишется в журнал ядра (`.log`) — время, параметр,
   старое и новое значение.
4. `rootcmd:` без параметров — не даёт списка скрытых команд, только подсказку:
   «доступ к секретам ограничен».
