# A1 — нативный интерпретатор ядра (bring-up Ф2, шаг 1)

Статус: ✅ принято, 2026-11-18. Связано: `CtOs/BRINGUP_SPEC.md` (Ф2, вариант A),
TKT-056 / TKT-055.

## Что сделано

`CtOs/native/native_rt.c` — нативный (C11, MinGW gcc) интерпретатор подмножества
опкодов CtOs v1.1, реально исполняемых модулями ядра:

- `NOP`, `INIT`, `ALLOC_ST`, `CALL`, `RET`, `TERM`, `JZ`, `JMP`;
- `CONST`, `LOAD` (режимы `0x14/0x15/0x16/0x17/0x18/0x19/0x1A/0x1B`);
- `STORE_A`, `STORE_AT`, `INCELL`, `INCELL_IND`, `STORE_IND`;
- `OUTCELL`, `OUTCELL_V`.

Ячейки `cell:raw` — разреженная хеш-таблица на 2²⁰ записей; адрес отсутствует
⇒ честное 0, как в `ctos_vm.py`. Вся арифметика и запись строго 32-битные
(`& 0xFFFFFFFF`, контракт B-13 / TKT-009). `STORE_IND` с нулевым указателем —
честный `FATAL`, а не тихая запись.

Заголовок v1.1 проверяется CRC-32 тела (zlib-совместимый, таблица
`0xEDB88320`), как в эталонной VM. v1.0 принимается с явным `WARN`.

## Честные границы (НЕ сделано в A1)

- syscall/NID (`0x13`), файловый слой, контекстные NID `0x150..0x154`,
  таймер/irq-тик (`0x153/0x154`), `ASMBLOCK`, сетевые opcode —
  при исполнении дают `FATAL: opcode не в подмножестве A1`. Это не баг,
  а явное объявление границы шага.
- Boot shim под **legacy BIOS моноблока** (сырой MBR, real mode → защищённый
  режим, INT 13h, VGA text/COM1) / QEMU — нет. По уточнению владельца, на
  R3700 есть только очень старый BIOS-аналог; UEFI/GRUB не подтверждены.
  В этом окружении QEMU отсутствует, поэтому «работает на железе»
  **не заявляется**; A1 — хостовый нативный рантайм для сверки семантики.
- Нативная периферия, HAL физической памяти, прерывания — шаги A2/A3/Ф3.

## Приёмка

`python -X utf8 Python_compiler/verify_native_rt.py`:

| Бинарь | Порты | Опкоды | Ячейки |
|---|---:|---:|---:|
| `CtOs/memmgr.ctos` | 13/13 | 1395 | 73 |
| `CtOs/kernel_sched.ctos` | 12/12 | 132552 | 313 |

Побайтовая сверка последовательности `PORT <port> <value>` против трассы
`ctos_vm.py --trace`, плюс совпадение счётчика опкодов и числа живых ячеек.
Негатив: порча одного байта тела ⇒ обе программы отказываются с диагностикой
`[TKT-040] честный брак целостности` (VM rc=1, native rc=1).

## Сборка/запуск

```
gcc -O2 -std=c11 -Wall -Wextra -o CtOs/native/native_rt.exe CtOs/native/native_rt.c
CtOs/native/native_rt.exe CtOs/memmgr.ctos events.txt
python -X utf8 Python_compiler/verify_native_rt.py   # автобилд в TEMP, дерево не засоряется
```
