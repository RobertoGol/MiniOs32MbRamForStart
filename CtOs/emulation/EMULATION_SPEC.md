# 🎮 EMULATION_SPEC — игры PSP/PS1/PS2/PS3 на CtOs (ACER Revo R3700)

Место: `CtOs/emulation/`. Статус: спецификация.
Цель пользователя: **все игры всех PlayStation — PSP (1004 Fat / 1008 Street /
2000 / 3000 / Vita), PS1, PS2, PS3 — запускаются на ACER Revo R3700 так,
чтобы было лучше, чем на официальном железе.** Аргумент честный: технологии
и логика ушли вперёд с тех времён — железо старое, но ОС может всё
компенсировать (это и есть девиз «ОС не парит железо»).

## Почему это честно возможно (Design Law)

Официальное железо тех лет работало на CPU/ОЗУ, которые сегодня многократно
побиты современным x86. Р3700 слаб, но его сила — не в сырой скорости,
а в том, чего у старых консолей не было:

1. **современный код генерации/трансляции** (мы сами пишем компилятор
   KINII — честный опыт честного эмуль-кодогена);
2. **ОС-уровневое кэширование** (UMD Cache честный аналог уже в списке
   настроек PSP-ветки);
3. **No-HZ**: пустых тиков во время сна ядра нет — честный CPU целиком
   эмулятору (спринт Д);
4. **загрузка уровней по требованию** из ISO вместо честного чтения
   лазером с честной скоростью привода (PS2/PS3 грузились диском минуты — с
   SSD/USB на R3700 честно быстрее).

## Архитектура: ядра-платформы как PRX-модули

| Платформа | Ядро (фоновый `.ctos`-модуль) | Честный приоритет | Сложность |
|---|---|---|---|
| PS1 | `ps1.ctos` | 1-й — самый лёгкий CPU + честный GTE | низкая |
| PSP | `psp.ctos` | 2-й — MIPS + GPU-командный буфер | средняя |
| PS2 | `ps2.ctos` | 3-й — EE/VU, IPC между ядрами VM | высокая |
| PS3 | `ps3.ctos` | 4-й — Cell PPU (SPU честно сведён до SIMD) | очень высокая |

Правила честного порядка: PSP/PS1 — первые живые цели (лучший
честный прирост на слабой железке). PS3 — только после честного
прецедента PS2 (иначе вряд ли). Никаких обещаний «всё и сразу»: каждый
платформенный спринт — честный прогон одной игры-эталонa.

## Одноразовый честный скан дисков (требование пользователя)

На всех дисках — **одно** честное сканирование при монтаже (тест был
закрыт в спринте Монтирование: маршруты msN/hd0 честны):

* ядро перечисляет порты честно, монтирует живые носители;
* **ровно один обход** каждого маршрута: найти честные папки
  `ISO/` (образы дисков) и `Games/` с подпапкой `Save/`;
* результат честный кеш в памяти ядра: таблица соответствий
  (маршрут → папка игр → папка сохранений), копится в журнале
  `FS_SCAN_LOG`; повторный скан — только по честной команде
  (терминал `fs_rescan` / Settings → Storage → «Обновить»);
* ОС и рантайм живут на **главном диске** (SD/USB/WD — не важно):
  честная метка «системный» ставится при установке (спринт
  установщика уже даст honest контроль); её приоритет над всеми
  пришедшими USB-дисками честен;
* диск отвалился в момент игры → честная ошибка носителя (как в
  спринте Монтирование), игра честно ставится на паузу, данные
  сохранений другого диска честно не затрагиваются.

## Сохранения (Save) — честные правила

* путь сохранения всегда честен: `<Games>/Save/<GameID>/`;
* запись сохранений — только на **главный диск** (даже если игра
  лежит на `ms0:`), честная защита от потери при выдёргивании
  карты с игрой;
* автосейв в фоне — честная задача планировщика (SLEEPING между
  честными точками, No-HZ экономит тики).

## Powermanagment — честный потолок 13 Вт (Design Law)

Связка с SETTINGS_SPEC (Секция «Энергосбережение»). Главная честная
идея для эмуляции: **честный governor CPU** — сама ОС ставит тик частоту
согласно нагрузке:

| Режим | Load CPU | Действие честное |
|---|---|---|
| idle (XMB) | < 20 % | честное снижение частоты + No-HZ |
| game PSP | 40–90 % | честная частота +, вентилятор честен |
| game PS2/PS3 | > 90 % | честная частота max, ТЕРМО-честный предохранитель |
| сон | 0 | честное глубокое сна (из user-Настроек) |

Термопредохранитель честный: датчики температуры → честное снижение
частоты → честная паника только при честном перегреве (пункт списка
«скрытые лог вентилятора и датчиков» — Секретные).

## Честные вехи (без ложных дат)

1. **M1** — файловая модель + одноразовый скан папок (стадия-0).
2. **M2** — PS1 `ps1.ctos`: честный запуск одного ROM-эталона (Boot,
   CPU, VRAM, потом звук).
3. **M3** — PSP `psp.ctos`: MIPS-ядро + честный GPU-буфер.
4. **M4** — PS2 `ps2.ctos` (EE), PS3 — M5 (Cell).
5. Fastfetch — в конце: честный экран по реальным ячейкам ядра
   (BOOTLOG_SPEC).

Никаких ложных дат: каждая веха закрыта честным регрессом и честным
запуском эталона.
