# 📁 EXPLORER_SPEC — File Explorer CtOS (модель Win10, не код Microsoft)

Место: `CtOs/explorer/`. Статус: спека + **реализация стадии-0**
(`explorer.kt` → `explorer.ctos`, 2026-11-01, [[TKT-038_file_explorer]]).
UI (TkExplorer) — прикладной слой CtMusic.

## Что берём из модели Win10 (честно переделанное)

- слева дерево: «Быстрый доступ», Sys-область, диски/монтирования;
- адресная строка с хлебными крошками (сегмент = клик);
- поиск по дереву в памяти — мгновенный (правило слабого железа: никакого
  polling и фоновых индексов);
- список с колонками: имя / дата изменения / тип / размер;
- контекстное меню: открыть, копировать, вырезать, вставить,
  переименовать, удалить (в корзину), свойства;
- корзина — честная системная папка: удаление = ПЕРЕНОС, не чистка;
- свойства: размер в СЛОВАХ ФС (4 байта), дата, контрольное слово;
- команды терминала в стиле Windows.

## Формат узла (совпадает со слоем ФС и реестра)

Узел — 32 байта (8 слов):

| Смещение | Поле | Смысл |
|---|---|---|
| +0 | id | номер узла |
| +4 | parent | родитель (0 = корень/монтирование) |
| +8 | tag | имя, 4 ASCII LE |
| +12 | kind | 1 папка, 2 файл, 3 монтирование, 4 системная папка (RO), 5 системный файл (RO) |
| +16 | size | размер в СЛОВАХ ФС (4 байта) |
| +20 | mtime | честная дата изменения |
| +24 | flags | 0 обычный, 1 в корзине, 2 вычищен |
| +28 | seal | контрольное слово узла ([[TKT-040_integrity_check]]) |

Дерево модели: 20 узлов, `EXPL_TREE 0x00E71000` (конец `0x00E71280`).
Монтирования — как в [[TKT-019_mount_routes]]: `ROOT` (hd0) и `MSD0` (ms0).
Приложения — как в [[TKT-041_apps_base_layout]]: `\APPs`, `\Data`.

## Корзина

- `del` = перенос: `parent -> RECy` (узел 20) + запись журнала
  `(id, прежний parent, tag, размер)` 16 Б на запись, до 8 записей.
  Данные узла (размер/контрольное слово) честно НЕ меняются.
- возврат `restore` — по записи журнала, ровно как было.
- очистка `empty` — только при явном `Empty_Flag = 1`; без него честный
  отказ `0x7113`, содержимое цело.
- после очистки узел — честная «могила»: `parent = 0xFFFFFFFF`
  (места нет), `size = 0`, `flags = 2`; журнал корзины пуст.

## Команды терминала (Windows-style)

Таблица из 12 команд по 12 Б (`CMDS 0x00E78000`): `tag`, `target`, `kind`.
`kind 1` = настоящий syscall файлового слоя (0x130..0x137); `kind 2` =
внутренняя FS-операция Ring 0 (0x7201..0x7208). Подмены нет:

| Команда | Цель | Что это |
|---|---|---|
| dir | 0x7201 | список папки в памяти |
| cd | 0x7202 | переход |
| type | **0x137** | FILE_GET — настоящее чтение слова |
| copy | **0x130** | FILE_BEGIN (далее PUT/U16/U8/END) |
| del | 0x7203 | в корзину (перенос) |
| ren | 0x7204 | переименование |
| md | 0x7205 | создать папку |
| rd | 0x7206 | удалить папку |
| cls | 0x7207 | очистить экран |
| mnt | 0x7208 | перечитать монтирования |
| ver | **0x135** | FILE_SEAL — контрольное слово артефакта |
| seek | **0x136** | FILE_SEEK — позиция записи |

Неизвестная команда — честный отказ `0x7110` (тишины нет).

## Коды отказов

| Код | Смысл |
|---|---|
| 0x7110 | нет такой команды |
| 0x7111 | возврат того, что не в корзине |
| 0x7112 | переименование RO-узла (kind 4/5) |
| 0x7113 | очистка корзины без явного флага |
| 0x7114 | нет такого узла |
| 0x7115 | честный отказ ёмкости колонок (больше 4) |

## Что проверено живьём (2026-11-01)

`explorer.kt` → 7718 Б, 8025 опкодов, VM exit 0.

- дерево 20×32 Б, курсор `0x00E71280`; «Быстрый доступ» 4 ссылки;
- крошки `Game\Save` = `[1, 5, 6]` (корень → лист, честный разворот);
- колонки `\APPs` = `[8, 9]` (2 ребёнка, без переполнения);
- честное переполнение корневого списка: 6 детей при ёмкости 4 →
  показаны ровно первые 4 (`2,3,4,5`), флаг 1, код `0x7115`;
- поиск `THm1` → узел 10, ровно 1 находка;
- свойства `APPb`: id 8, тип файл, 512 слов, дата `0x00010007`, seal 1;
- корзина: `APPb` → parent 20, `flags=1`, размер 512 цел; возврат →
  parent 2, `flags=0`, размер 512; возврат не из корзины → `0x7111`;
- очистка без флага → `0x7113`, данные целы; с флагом → `size=0`,
  `flags=2`, `parent=0xFFFFFFFF`, журнал пуст;
- переименование `THm1 → THm9` легло; `SYS` (kind 4) → `0x7112`;
- акцент темы унаследован из `SHELL_PAL` (`0x2048`, источник `SHEL`);
- таблица 12 команд: `dir → 0x7201` (FS), `type → 0x137` (syscall);
  неизвестная `CHO ` → `0x7110`;
- неизвестный узел 99 → `0x7114`, найденного нет;
- все маркеры `0x9F01..0x9FFF` ОК, ложных браков `0x99A0..0x99C6` нет.
