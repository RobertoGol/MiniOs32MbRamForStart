# Веха-10: 'wc' — пятый честный поглотитель nb-числа (TKT-052)

Дата: 2026-11-06. Изменения: `Compiler/stage1_compiler.kt` — сайт 'wc' (поглощение
с честной цепью равенств номинала), define BRK_WC_RANGE 0x0D + 7 defines
честного номинала слот-зоны, static Sl_OK (+ завод в main), комментарий шапки.
Бинарь `stage1_compiler.ctos` пересобран: 18 424 → 18 748 Б.

## Честная семантика
- Форма `nb X wc` (X = честное nb-число, цифры отдельными словами):
  `wc` ЗАБИРАЕТ открытое число БЕЗ эмиссии: если Num_Acc равен честному
  номиналу рабочих слотов, `W_Current = BE32(Num_Acc)` (абсолютный адрес),
  Num_Pending/Num_Acc = 0, W_Pending = 0 (форма самодостаточна), acc НЕ
  меняется (поглотители вехи-8 не эмитят — acc живёт своим ходом).
  Как у sv/va/gp/sp: длина эмиссий других слов НЕ меняется.
- Честный номинал: {0x00F00FF1 (WORK_CELL), 0x00F00FF3..0x00F00FF8 (W2..W7)}.
  Системные 0x00F00FF0 (Stream_Emit) и 0x00F00FF2 (FILE_EOF) в номинал НЕ
  входят — 'wc' выбирает только РАБОЧИЕ слоты. '<=' на стадии-0 нет —
  проверка честно развёрнута в цепь из 7 равенств (флаг Sl_OK).
- Новый честный брак BRK_WC_RANGE 0x0D (fail-fast ДО эмиссии, позиция =
  слово 'wc'): Num_Acc вне номинала.
- Эволюция вехи-8: список непоглотителей 13 → 12 сайтов ('wc' выведен;
  'sv','va','gp','sp' остаются поглотителями; остальное честно б ракует 0x0C).
- Цифровая форма 'wc d' (0..5 → WC_BASE+d) НЕ тронута; сайты цифр и 'ne'
  не изменены — ноль структурного регрессионного риска.

## Честная сила (что короткой формой не достать)
WORK_CELL 0x00F00FF1 недостижим 'wc d' (короткая форма только F3..F8);
из nb-литерала возврат на WORK честен: `... nb 1 5 7 3 2 7 2 1 wc ...`.

## Пробы (факт сборки 2026-11-06, бинарь 18 748 Б)
- М1 temp `nb 1 5 7 3 2 7 2 1 wc te`: 46 Б, 0xFF, 11 токенов,
  эмиссия ТОЛЬКО TERM (поглощение без CONST — честно).
- `pos_wc1.words` (23 слова): 81 Б, 0xFF. Байты: CONST 7/STORE_AT F1,
  CONST 9/STORE_AT 0x00F00FF5 ('wc 2' — цифровая форма), LOAD[0x19]
  BE32(0x00F00FF1) ('va' после поглощённого wc — W из литерала возврат
  на WORK), OUTCELL_V, TERM. VM: acc 7 → cell[F1], acc 9 → cell[F5],
  va: acc = 7, порт ← 7; SUCCESS.
- `pos_wc2.words` (13 слов) `nb 1 5 7 3 2 7 2 1 wc sv pr te`: 60 Б, 0xFF,
  13 токенов, БЕЗ CONST; VM: cell[F1] <- 0 (acc мог быть 0 — честно),
  порт ← 0; SUCCESS. Поглощение доказано отсутствием эмиссии.
- `neg_wc1.words` `nb 6 wc`: 0x0D@2, 0xFE, поток пуст.
- `neg_wc2.words` `nb 1 5 7 3 2 7 2 0 wc` (0x00F00FF0 = Stream_Emit,
  системная — вне номинала): 0x0D@8, 0xFE, поток пуст.
- Урок честный (пойман m1-пробой 0x01@9): первое решение поглотителя НЕ

  токена и Found_Flag (как все поглотители вехи-8).

## Границы (не трогаем)
- Стенд-зеркало stage1_selftest.kt не тронуто (догоняет при спринте стенда).
- VM не тронут: 0x55/0x12 честны; адресная защита VM (адрес 0) остаётся.
- NB накопитель десятичный (0..9) — бутики не hex; 8-значные честные числа
  собираются честной цепочкой Num_Place (10 сложений на цифру).
- 'wc' при Num_Pending ВНЕ поглощения больше не бракует 0x0C — 'wc' сам
  поглотитель; `wc nb X wc` (второй 'wc' при W_Pending=0 после честного
  поглощения) честно повторяет выбор.
