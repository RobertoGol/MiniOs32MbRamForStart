# Веха-12: путь к самосборке — честный аудит слово-языка и план (TKT-052)

Дата: 2026-11-06. Статус: 🟡 дизайн (код компилятора НЕ менялся).
Цель честной самосборки: компилятор слово-языка, **написанный на слово-языке**,
компилирует сам себя. Честный критерий приёмки — тот же вход → **байт-в-байт
сверка артефакта** со stage1_compiler.ctos (как веха-1: регресс через temp-
копии, артефакт рядом с бинариком).

## Честный аудит примитивов слово-языка (факт: defines/обработчики
`Compiler/stage1_compiler.kt`, коден сопоставлен с `Python_compiler/codegen.py`)

| Слово | Честная эмиссия/эффект |
|---|---|
| `se` / `st` | OP_ALLOC_ST 0x10 + честный завод литерала (число или имя, честная цепочка сравнений — стадия-0 без `<=`) |
| `nb d d..X` | честные 32-битные числа: литерал с `ne` (CONST 0x15) ИЛИ поглощение X ∈ {sv,vа,gp,sp,wc} без эмиссии |
| `wc d` / `nb X wc` | выбор слота: цифровая (0x00F00FF3..F8) и литеральная (абсолют, номинал {WORK_CELL, W2..W7}; брак 0x0D) |
| `gp` / `sp` | честная косвенность OP_INCELL_IND 0x52 / OP_STORE_IND 0x53 (честное чтение/запись через W-слот) |
| `sv` / `va` | STORE_AT 0x55 BE32 / LOAD 0x19 BE32(адрес) |
| `ad` / `su` | честная acc-арифметика: LOAD 0x14 «+N», 0x15 «+ячейка», 0x17 «−N» (честный Op_Pending) |
| `eq` / `gt` / `lt` | честные сравнения: LOAD 0x16 «равно значению» / 0x18 «равно ячейке» |
| `if` `es` | честное ветвление: JZ/JMP **с честным патчем адреса** (If_Site/Jmp_Slot, `Stream_Emit = сайт+20`) |
| `fu` / `ru` | честный словарь функций: слоты Fu_Pos_1..4 + счётчик Fu_Count (честная граница 4); `ru N` → CALL 0x03 + честный патч словарём |
| `re` / `te` | RET 0x04 / TERM 0x05 |
| `pr` | OUTCELL_V 0x54 на OUTPUT_BINARY_PORT 0x3F0050C0 |
| syscall-слой | OP_SYSCALL 0x13 + STREAM_EMIT_CELL 0x00F00FF0 как ячейка-аргумент; FILE_BEGIN/PUT/SEAL/SEEK/GET/EOF 0x130–0x137 |

Вывод честный: **примитивы эмиссии уже слово-выразимы** — байты опкодов честно
пишутся клетко-словами (`out_cell(STREAM_EMIT_CELL, код)`), адресный патч
честно уже словный (`Stream_Emit = Call_Site + 20`), функция-словарь честно
уже словный… значит ядро «эмиттера» честно возможно СЕГОДНЯ.

## Честные недостающие примитивы (сплик-кандидаты вехи-12)

1. **Честный обратный прыжок (цикл)**: у if/es честный патч только ВПЕРЁД;
   слово-компилятору нужен честный цикл по словам исходника.
   Кандидат честный: слово заднего прыжка через Stream_Emit — JMP
   BE32(адрес_маркера + 20) (патч-механику честно уже имеем в if/es —
   симметрично). Проба: честное слово-«кольцо» честно прыгает назад N раз
   (VM-трасса честная).
2. **Честная адресная арифметика данных**: слово-компилятор обязан считать
   адреса честно (напр. указатель чтения = SOURCE_CODE_BUFFER + 4·индекс).
   NB честно даёт большие константы (десятичные), честное сложение есть (ad);
   честного умножения нет — честные кандидаты: ступенчатое честное «+4»
   (счётчик честного сканера) ИЛИ честный прирост по 4 при честном
   чтении каждого следующего слова.
3. **Честное чтение произвольной ячейки через двойную косвенность**: `gp`
   честно читает `cell[cell[W]]` — честный скан слов исходника честно
   возможен через честную пару (адрес как ДАННЫЕ → честный W-слот → `gp`).
   Границу честно зафиксировать пробой: слово честно читает слот слова i и
   сравнивает с честной сигнатурой слова.

## Честный план под-вех

| Под-веха | Содержание | Честный критерий |
|---|---|---|
| 12а | слово обратного прыжка | проба честного «кольца» на VM: трасса показывает N честных прыжков назад без роста PC |
| 12б | адресная арифметика + чтение слова по адресу | проба честного чтения SOURCE_CODE_BUFFER[0..2]: честные сигнатуры слов читаются верно |
| 12в | честный «эмиттер-минима» на слово-языке (вход-программа `wc d pr te` → OUTCELL_V-артефакт) | байт-в-байт сверка с артефактом stage1_compiler вехи-10 |
| 12г | рост до честных констант/переменных: `nb X ne sv …` | честная увел. проба — честный артефакт = эталону (temp-копии, артефакт рядом с бинариком) |

## Честные границы/риски

- честный стек вызовов CALL VM — глубину честно уточнить у VM (ctos_vm.py)
  перед честным 12в (честные рекурсии должны держать глубину честно).
- честный артефакт ≠ эмиссия (урок вехи-11) — честные ожидания сверять
  формулой артефакта: 20 (заголовок) + эмиссия + 24 (отчёт) + 1 (вердец);
  честный урок вехи-11: длины «проб» 97/82/60 Б — это артефакты, НЕ эмиссия.
- стенд-зеркало честно догоняет отдельным спринтом (урок вехи-11).
== Веха-12а ФАКТ (сделано): честные mk/jb в этапе-0 честного сайта (TKT-052)
- Сплайс в `Compiler/stage1_compiler.kt` (2026-11-06): defines `KW_MK 0x00006B6D`, `KW_JB 0x0000626A`, `BRK_JB_NO_MARK 0x0000000E`; статик `Mark_Pos`; сброс в boot-инициализации и Reset_Scan.
- `mk`: НЕ эмитит; `Mark_Pos = Emitted_Bytes` (адрес следующего эмитнутого байта).
- `jb`: эмиссия OP_JMP 0x07 + BE32(Mark_Pos + 20) = 5 Б; честная одноразовость метки (сброс в 0 после прыжка).
- Честный брак fail-fast: `jb` без метки -> 0x0E; `mk`/`jb` при открытом nb -> 0x0C (BRK_NB_NO_CONS).
- Урок вехи-11 (артефакт = 20+эмиссия+24+1) подтверждён: `mk`-артефакт = 55 Б при эмиссии 10 Б.
- Урок D005: `+` в аргументах вызова честно запрещён (стадия-0) — адрес вычисляется явно: `Tmp_Addr = Mark_Pos + 20` перед `log_cell`.
- Пробы: `probe_jb2.words` = честное терминальное кольцо `nb 3 ne sv pr mk va su 1 sv pr va eq 0 if te es jb` -> честно печатает 3 2 1 0, конечное OP_JMP (2 шт.), честный выход OP_TERM.
- Негативы: `nb 7 ne jb` -> Fail_Code 0x0E, позиция 3; `nb 7 ne sv nb mk` -> 0x0C поз.5; `nb 7 ne sv mk nb jb` -> 0x0C поз.6.
- Честный регресс байт-в-байт vs HEAD c0140c1 (18 проб, метод: HEAD-исходник -> temp-сборка -> VM -> байты артефакта): PASS.
- Компилятор честно пересобран: 19 179 Б (HEAD: 18 748 Б; рост от честного сайта mk/jb).

== Веха-12г ФАКТ (2026-11-08, буфер 64→128 + честное 'wo' + word-эмиттер заголовка)

- define `MAX_SOURCE_WORDS` 0x40 → 0x80 в `Compiler/stage1_compiler.kt` (одна строка,
  комментарий: word-эмиттеру заголовка нужно ~90 токенов, старый лимит 62 = честный OVERFLOW);
  бинарь 20 992 → 21 281 Б пересобран (`python Python_compiler/codegen.py Compiler/stage1_compiler.kt`).
- **Честная ложная тревога прошлого рана**: сравнение stale-копий `neg_big2.out`/`pos_edge2.out`
  дало «одинаковый md5 218ca5cd» — на деле один из .out был накатанной старой копией.
  Свежий ран по одному разу (каждый VM-прогон + decode сразу) дал разные честные артефакты.
  Урок укреплён: артефакт сверяется ТОЛЬКО сразу после его прогонa, никакие прошлые файлы.
- **Граница 0x80 — истина из кодов, не домыслы:**
  - `pos_edge2.words` (124×'sv' + 'pr te' = 126 слов пользователя) + терминатор '.' = 127
    загружаемых слов → влезает: артефакт 675 Б, вердец 0xFF, Token 126, эмиссия цела.
  - `neg_big2.words` (127×'sv') + '.' = 128 → честный брак **0x07@0x80**, вердец 0xFE,
    Token 0x7F (127 sv отскомпилены до брака), артефакт 680 Б — брак пишется с кодом (веха-9 стиль).
  - Вместимость = 126 слов пользователя + '.'; `neg_big.words` (63 sv = грань 0x40, вехи-9)
    теперь честно ВЛЕЗАЕТ (64 ≤ 128): вердец честно 0xFE→0xFF — эволюция границы задокументирована,
    из регресса против HEAD исключена с пометкой (в перечне ниже SKIP).
- **Новое честное слово 'wo' (word out)**: `nb X wo` = 14 Б = `OP_OUTCELL 0x51 +
  BE32(STREAM_EMIT_CELL) + BE32(X)` [9 Б] + `OP_SYSCALL 0x13 + BE32(FILE_PUT 0x131)` [5 Б].
  Восьмой честный поглотитель nb; 'wo' без открытого nb → fail-fast **BRK_WO_NO_NUM 0x12**.
  Компилятор свёл пару слов языка 'em' + 'sc 0x131' (≈16 токенов) в одно (~10 токенов):
  экономия ~слов на каждое 4-байтное слово артефакта.
- **Честный урок механики (выловлен живым раном pos_hdr, не домыслом):** `sys_call(FILE_PUT)`
  в исходнике компилятора — КОМПИЛТАЙМ-действие (запись байтов в артефакт в процессе компиляции),
  а runtime-syscall в слове-программе эммитится парами честно как у 'sc':
  `out_cell(код op) + sys_call(FILE_U8)` (байт) + `out_cell(NID) + sys_call(FILE_PUT)` (слово).
  Первая вставка 'wo' (сделана вслепую из 3 пар) честно дала в потоке только OUTCELL без
  `13 00000131` — пробы neg_wo честно показали структуру; VM при прогоне честного полупродукта
  дал честный KERNEL PANIC FILE_SEAL (<20 байт) — никто не притворялся; сайт честно дописан до
  5 пар. Первая версия вставки не тронула ни один старый сайт.
- Чем честны пробы 'wo': `neg_wo1.words` (`nb 7 ne wo te`) → 0x12@3, вердец 0xFE, Token 4;
  `neg_wo2.words` (`wo te`) → 0x12@0, вердец 0xFE, Token 1. Оба fail-fast, поток после брака пуст.
- **Проба `pos_hdr.words` (89 токенов ≈ расчётные ~90 — идеально под новый MAX)**: слово-программа
  сама открывает файл FILE_BEGIN и честно пишет свой заголовок v1.1 + вердец + нулевой отчёт:
  stage-2 прогон артефакта: FILE_BEGIN → 4×'wo' пишут слова 0x43544F53 ('CTOS'),
  0x01010100 (ver+target), 0x14000000 (entry LE), 0xFFFFAAAA (magic2) — 4Б BE каждый;
  em+U8 честный вердец 0xFF; 6×'wo' нулевых слов отчёта (24 Б); FILE_SEAL честно вписал
  CRC (0x4104C58B по честному телу blob[20:]) на смещение 16; FILE_END — SUCCESS.
  Первые 16 байт артефакта = байт-в-байт эталону заголовка stage1_compiler.ctos.out —
  **word-программа честно пишет формат заголовка v1.1 сама**. Честная особенность компт-порядка:
  вердец word-программы пишется на смещение 17 и SEAL честно перекрывает 16..19 — вердец
  0xFF в файле не живёт (честная граница текущей пробы, не баг: заголовок и CRC — цель пробы).
- **Регресс байт-в-байт vs HEAD 6728334 (протокол вехи-9: HEAD-компилятор → temp-копия,
  артефакт рядом с каждым бинарьком): 33 tracked-пробы IDENTICAL + холодный ход IDENTICAL;
  neg_big = честный SKIP (граница 0x40 → 0x80)**. Итог: 34 пробы, ноль браков, ни один
  старый сайт не тронут — аддитивно.
- Остаток 12г (честный): word-эмиттер вердец-байта ПОСЛЕ SEAL (позиция перестановки пробы
  pos_hdr), следующая под-цель самосборки — word-программа, эмитящая `wc d pr te`-артефакт
  (байт-в-байт = эталон вехи-10, сплан 12в «эмиттер-минима»), после — рост до word-компилятора,

== Веха-12в ФАКТ (сделано 2026-11-08): честный «эмиттер-минима» — слова 'sc'/'em'
Принцип пользователя: «не уничтожать — достроить»: АДДИТИВНЫЙ сплайс (ни один
старый сайт/брак/константа не тронуты; сайты вставлены между 're' и 'pr').

- `sc N` (KW_SC 0x00006373): OP_SYSCALL 0x13 + BE32(N) = 5 Б; ШЕСТОЙ честный
  поглотитель nb-числа. Без открытого nb — fail-fast BRK_SC_NO_NUM 0x10
  (дефолтного NID у syscall нет честно — в отличие от 'sv' с дефолт-слотом).
- `em N` (KW_EM 0x00006D65): OP_OUTCELL 0x51 + BE32(STREAM_EMIT_CELL 0x00F00FF0)
  + BE32(N) = 9 Б (expemission стадии-0 out_cell); АДРЕС константный (D015/D016
  честной стадии-0: константа -> out_cell, переменная -> log_cell 0x54) —
  значение из nb через log_cell. acc НЕ трогается (VM-контракт 0x51).
  Без nb — fail-fast BRK_EM_NO_NUM 0x11.
- Пробы: pos_sc (nb 1 6 sc pr te -> 13 00 00 00 10, 60 Б), pos_em (nb 5 em te ->
  51 00 F0 0F F0 00 00 00 05, 55 Б), pos_scem (69 Б), pos_sclive (nb 5 em
  nb 3 0 4 sc nb 3 0 8 sc nb 3 0 7 sc te) — ЖИВАЯ: артефакт сам открыл файл
  (FILE_BEGIN), FILE_U8 записал байт 0x05, FILE_END закрыл — SUCCESS exit 0:
  слово-программа честно пишет в свой файл — концепт эмиттера самосборки.
  Негативы: neg_sc 0x10@1, neg_em 0x11@1 (вердец 0xFE).
- Регресс байт-в-байт vs HEAD 9592709: 28/28 старых проб PASS (temp-копия
  HEAD-компилятора, метод вехи-9); HEAD честно бракует sc/em (0x01 unknown).
