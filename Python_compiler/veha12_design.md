# Веха-12: путь к самосборке — честный аудит слово-языка и план (TKT-052)

Дата: 2026-11-06. Статус: 🟡 дизайн (код компилятора НЕ менялся).
Цель честной самосборки: компилятор слово-языка, **написанный на слово-языке**,
компилирует сам себя. Честный критерий приёмки — тот же вход → **байт-в-байт
сверка артефакта** со stage1_compiler.ctos (как веха-1: регресс через temp-
копии, артефакт рядом с бинариком).

## Честный аудит примитивов слово-языка (факт: defines/обработчики
`Compiler/stage1_compiler.kt`, коден сопоставлен с `Python_compiler/codegen.py`)

| Слово | Честная эмиссия/эффект |
|---|---|
| `se` / `st` | OP_ALLOC_ST 0x10 + честный завод литерала (число или имя, честная цепочка сравнений — стадия-0 без `<=`) |
| `nb d d..X` | честные 32-битные числа: литерал с `ne` (CONST 0x15) ИЛИ поглощение X ∈ {sv,vа,gp,sp,wc} без эмиссии |
| `wc d` / `nb X wc` | выбор слота: цифровая (0x00F00FF3..F8) и литеральная (абсолют, номинал {WORK_CELL, W2..W7}; брак 0x0D) |
| `gp` / `sp` | честная косвенность OP_INCELL_IND 0x52 / OP_STORE_IND 0x53 (честное чтение/запись через W-слот) |
| `sv` / `va` | STORE_AT 0x55 BE32 / LOAD 0x19 BE32(адрес) |
| `ad` / `su` | честная acc-арифметика: LOAD 0x14 «+N», 0x15 «+ячейка», 0x17 «−N» (честный Op_Pending) |
| `eq` / `gt` / `lt` | честные сравнения: LOAD 0x16 «равно значению» / 0x18 «равно ячейке» |
| `if` `es` | честное ветвление: JZ/JMP **с честным патчем адреса** (If_Site/Jmp_Slot, `Stream_Emit = сайт+20`) |
| `fu` / `ru` | честный словарь функций: слоты Fu_Pos_1..4 + счётчик Fu_Count (честная граница 4); `ru N` → CALL 0x03 + честный патч словарём |
| `re` / `te` | RET 0x04 / TERM 0x05 |
| `pr` | OUTCELL_V 0x54 на OUTPUT_BINARY_PORT 0x3F0050C0 |
| syscall-слой | OP_SYSCALL 0x13 + STREAM_EMIT_CELL 0x00F00FF0 как ячейка-аргумент; FILE_BEGIN/PUT/SEAL/SEEK/GET/EOF 0x130–0x137 |

Вывод честный: **примитивы эмиссии уже слово-выразимы** — байты опкодов честно
пишутся клетко-словами (`out_cell(STREAM_EMIT_CELL, код)`), адресный патч
честно уже словный (`Stream_Emit = Call_Site + 20`), функция-словарь честно
уже словный… значит ядро «эмиттера» честно возможно СЕГОДНЯ.

## Честные недостающие примитивы (сплик-кандидаты вехи-12)

1. **Честный обратный прыжок (цикл)**: у if/es честный патч только ВПЕРЁД;
   слово-компилятору нужен честный цикл по словам исходника.
   Кандидат честный: слово заднего прыжка через Stream_Emit — JMP
   BE32(адрес_маркера + 20) (патч-механику честно уже имеем в if/es —
   симметрично). Проба: честное слово-«кольцо» честно прыгает назад N раз
   (VM-трасса честная).
2. **Честная адресная арифметика данных**: слово-компилятор обязан считать
   адреса честно (напр. указатель чтения = SOURCE_CODE_BUFFER + 4·индекс).
   NB честно даёт большие константы (десятичные), честное сложение есть (ad);
   честного умножения нет — честные кандидаты: ступенчатое честное «+4»
   (счётчик честного сканера) ИЛИ честный прирост по 4 при честном
   чтении каждого следующего слова.
3. **Честное чтение произвольной ячейки через двойную косвенность**: `gp`
   честно читает `cell[cell[W]]` — честный скан слов исходника честно
   возможен через честную пару (адрес как ДАННЫЕ → честный W-слот → `gp`).
   Границу честно зафиксировать пробой: слово честно читает слот слова i и
   сравнивает с честной сигнатурой слова.
