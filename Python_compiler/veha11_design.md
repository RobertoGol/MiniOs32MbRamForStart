## Честные уроки сплайса (v1 → v4)

- **Замена функций только по скобочному балансу**: текстовый поиск `'\n}\n'`
  в v1 срезал хвост (финальная глубина −5, коден D001).
- **Скобки в комментариях/`'#'`-литералах — шум**: сырая глубина бэкапа −5 и
  компилятора −3, честная (с отсечением `//`-строк и `'...'`) — 0. Баланс и
  извлечение функций считают только честные скобки.
- **`[2:]` по кортежу из 2 элементов — пустой кортеж**: v2 честно упал на
  assert'е «компиляторский скан промахнулся».
- **D010 поймал отсутствующий `OUTPUT_BINARY_PORT`**, честный свер имён
  functions-scan vs defines (137 идентификаторов кода, 6 системных имён).
- **D004 поймал двойные `;;`** — артефакт генератора лоадеров (114 шт).
- **Артефакт ≠ эмиссия**: длины артефактов проб (97/82/82/46/60 Б) — НЕ эмиссии.
  Честная формула: артефакт = 20 (заголовок) + эмиссия + 24 (6 слов отчёта) + 1
  (вердец). Эмиссии: probe_indirect 52, probe_num 37, pos_oper 37, m1 1 (TERM),
  pos_wc2 15.

## Границы (не трогаем)

- Компилятор `stage1_compiler.kt` не изменялся в вехе-11 (18 748 Б, веха-10).
- VM не тронут.
- Байт-в-байт регресс **не** применим между стендами разного размера: честные
  jump-цели сдвигаются fixup'ом. Честный критерий догона — функциональный
  (маркеры + вердец + отчёт). Дифф эмиссионного префикса со старым стендом =
  ровно 2 байта целей jump (0x105 → 0x193) + честный хвост.
