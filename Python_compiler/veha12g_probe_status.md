## Ключевые найденные факты (уроки)

1. `site_store` с базой `400` и `flag=0` писал в живой сайт `cell[401]` на каждом
   `es` (затирал if#1). База перенесена в `SITE_DUMP=392` (константа `CSDP=251`).
   Это починило `if if es es te` / `if if te es es te` без роста токенов.
2. `cstore` с свалкой `100` затирал `SLC` → безопасная свалка `CS_DUMP=124` через
   ячейку-константу `CSD=138`; `ABS(...,'aa')` требует открытого nb.
3. `ml d1 d2` — НЕ произведение: `ml 6 9` = `ml 6` + `OP_CONST 9`. Произведение
   только `ml d1 ml d2`. Двузначный `d2` (`ml 1 30`) тоже ломает компиляцию.
4. `'eq 20'` (две цифры) не работает как литерал; нужен либо `eq <одна цифра>`,
   либо сравнение через ячейку (попытка `ABS(CT20,'eq')` дала регресс 0/16/53).
5. `gp` — двойная косвенность; для `is_b2(tag)` нужно
   `wc 8 gp → TMPF=tag`, `ABS(TMPF,'va') + wc 8 sv → W8=tag`,
   `wc 8 gp → SCRV=is_b2`. Без middle-адреса `SCRV` получал TAG.
6. `sp` сохраняет acc по `cell[cell[W_Current]]` и **не сбрасывает** `W_Current`;
   замена `wc 8 sp` → `sp` в `cstore`/`site_store` сэкономила 12 токенов.
7. Sticky-флаг отказа: `BADJB := (MARKP==0 && JBFA==1) + BADJB_old` —
   запись `ABS(BADJB,'aa') + ABS(BADJB,'sv')` **после** вычисления члена;
   промежуточные суммы без записи теряются (регресс 6 OK-DIV).
8. PS-gate `+ ABS(BADJB,'aa')` перед `if#2` дал честное молчание на 14 jb-негах;
   попытка gate через `BSFA` не работает (BSFA==0 и на позитивах).
9. `FPOS` кольца растёт на `+2` на каждом `mk` (устаревший `TMPB` от предыдущего
   слова), поэтому второй `mk` портит `MARKP` на `+2`; исправление требует сброса
   `TMPB=0` перед `cstore(TMPB,KA,…)` — **+6 токенов**, что не влезает в
   текущий бюджет 4090/4094 без дополнительной оптимизации.
